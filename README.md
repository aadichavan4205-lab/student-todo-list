# Student To-Do List

## Project Description

Student To-Do List is a simple web-based application designed to help students manage their daily tasks and assignments.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Clear completed tasks
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Git Collaboration

The project is developed collaboratively using Git and GitHub.

Each team member works on a separate feature branch and creates a Pull Request to merge their work into the main branch.

### Branches

- feature/project-setup — Aadinath
- feature/todo-ui — Akash
- feature/todo-functionality — Anniruddh
- feature/testing-docs — Mayuresh

## Git Workflow

Each member follows this workflow:

1. Create a feature branch
2. Make changes
3. Check changes using git status
4. Stage changes using git add
5. Create a commit using git commit
6. Push the branch using git push
7. Create a Pull Request on GitHub
8. Review the changes
9. Merge the Pull Request into main
